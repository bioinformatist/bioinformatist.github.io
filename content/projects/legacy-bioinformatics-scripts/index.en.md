These scripts are work fragments from my early bioinformatics analysis years, preserved in their historical form.

They reflect the analysis contexts, data formats, and engineering habits I had at the time. They are not presented as currently maintained software, nor as recommended modern implementations.

## Source Archive

- [Python scripts](https://github.com/bioinformatist/bioinformatist.github.io/tree/main/static/archives/legacy-bioinformatics-scripts/python)
    - [PacBio processing tools](https://github.com/bioinformatist/bioinformatist.github.io/tree/main/static/archives/legacy-bioinformatics-scripts/python/pb_tools): early scripts for PacBio / SMRT data organization, read extraction, and XML handling.
    - [GTF annotation statistics](https://github.com/bioinformatist/bioinformatist.github.io/tree/main/static/archives/legacy-bioinformatics-scripts/python/GTF_statistics)
    - [BLAST table span filter](https://github.com/bioinformatist/bioinformatist.github.io/blob/main/static/archives/legacy-bioinformatics-scripts/python/blastTableSubjectSpanFilter.py): filters BLAST tabular output by subject-coordinate span.
    - [Miscellaneous scripts](https://github.com/bioinformatist/bioinformatist.github.io/tree/main/static/archives/legacy-bioinformatics-scripts/python): code collection and crawler demos.
- [Perl scripts](https://github.com/bioinformatist/bioinformatist.github.io/tree/main/static/archives/legacy-bioinformatics-scripts/perl)
    - [SAM / mpileup filters](https://github.com/bioinformatist/bioinformatist.github.io/tree/main/static/archives/legacy-bioinformatics-scripts/perl): scripts around mpileup, SAM, and PacBio read processing.
    - [PacBio read extraction and adapter handling](https://github.com/bioinformatist/bioinformatist.github.io/tree/main/static/archives/legacy-bioinformatics-scripts/perl): scripts for CCS, subreads, selected reads, and adapter-related handling.
    - [duplexes-related scripts](https://github.com/bioinformatist/bioinformatist.github.io/tree/main/static/archives/legacy-bioinformatics-scripts/perl): early utilities for small-RNA / read-pair analysis workflows.

# Storage profit transmission diagram

## Purpose

Explain that companies described as "storage stocks" do not share one profit
model. The diagram separates DRAM manufacturers, module vendors, interface-chip
vendors, equipment and materials suppliers, and device brands.

## Design notes

- Use the site's restrained black, orange, green, blue, purple, and red palette.
- Keep all labels factual and readable at mobile width.
- Do not imply that every company in one category has identical economics.

## Reproduction

Run `node build-article-assets.mjs`, then rasterize the generated SVG with
ImageMagick.

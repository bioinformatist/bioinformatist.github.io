# FOMO and relief-rally mechanism diagram

## Purpose

Contrast a gradually rising fundamental-value trend with a market-price path
that overshoots during FOMO, sells off rapidly, rebounds in a relief rally, and
then comes under pressure again.

FOMO and relief rally must be shown as time intervals, not point annotations.
Use shaded horizontal ranges to mark each process.

## Important limitation

This is a conceptual mechanism diagram. It is not a valuation model, a price
forecast, or a reproduction of any company's historical chart.

## Reproduction

Run `node build-article-assets.mjs`, then rasterize the generated SVG with
ImageMagick.
